# Final Reflection — Mission 1 to Mission 10

**Author:** Angel Mae Fernandez
**Course:** CCM101 — Cloud Computing
**Date:** September 2026

## The Journey
Mission 1 started with simple Linux commands. By Mission 5, I was writing Bash scripts. By Mission 8, I was automating infrastructure with Docker. At Mission 10, I architected a complete, secure, production-ready enterprise stack.

## What I Learned
1. **Architecture beats memorization** — reasoning about why components exist matters more than reciting commands.
2. **Security is removing access** — UFW Default Deny taught me every open port is a door.
3. **Automation is the superpower** — a server that backs itself up survives human forgetfulness.
4. **Containers are portable, not magic** — the docker-compose.yml IS the infrastructure.
5. **Documentation is deliverable** — my GitHub portfolio is a handover manual.

## Challenges Overcome
- MySQL 8.0 PROCESS privilege error → fixed using root + --no-tablespaces
- WSL2 + UFW interplay → Windows NAT governs exposure; UFW valid for real Linux VMs
- Persistent volume testing → data survives docker compose down/up

## Final Thought
I started as a student. I'm finishing as an architect. The difference is ownership.

**Be the pilot of AI, not the passenger.** ✅
