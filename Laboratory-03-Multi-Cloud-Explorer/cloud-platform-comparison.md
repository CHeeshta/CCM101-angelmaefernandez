# Cloud Platform Comparison

> **Laboratory 03 – Multi-Cloud Explorer**  
> **Objective:** Compare AWS, Microsoft Azure, and Google Cloud Platform based on their services, strengths, and suitable organizational use cases.

## 1. Introduction

Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP) are three of the major public cloud providers. Although all three platforms provide similar fundamental cloud capabilities, they differ in their service offerings, infrastructure, technology integrations, and areas of strength.

The comparison below highlights some of the major differences between the three platforms and helps identify which provider may be more suitable for different organizational requirements.

---

## 3. Comparison by Category

### Compute

All three providers offer virtual machine services for running applications and workloads.

- **AWS:** Amazon EC2
- **Azure:** Azure Virtual Machines
- **GCP:** Google Compute Engine

These services allow organizations to create virtual servers and select computing resources based on their workload requirements.

### Storage

Each provider offers scalable cloud storage for storing files, application data, backups, and other information.

- **AWS:** Amazon S3
- **Azure:** Azure Blob Storage
- **GCP:** Google Cloud Storage

### Networking

The three providers also provide virtual networking services that allow organizations to control communication between cloud resources.

- **AWS:** Amazon VPC
- **Azure:** Azure Virtual Network
- **GCP:** Google Cloud VPC

### Identity and Access Management

Identity services are used to control who can access cloud resources and what actions they are allowed to perform.

- **AWS:** AWS Identity and Access Management (IAM)
- **Azure:** Microsoft Entra ID
- **GCP:** Google Cloud IAM

---

## 4. Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers a very broad range of cloud services among the three providers. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, containers, and many other areas. This makes AWS a flexible option for organizations with different types of workloads.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** best integrates with Microsoft technologies because it is part of the Microsoft ecosystem. It works closely with technologies such as Windows Server, Microsoft Entra ID, Microsoft 365, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform (GCP)** is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes. Google developed Kubernetes and provides **Google Kubernetes Engine (GKE)**, a managed service for running containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **AWS** because it provides a broad selection of cloud services and supports many different types of workloads. Its combination of computing, storage, networking, database, and security services makes it a flexible choice for organizations with different cloud requirements.

---

## 5. Overall Comparison

| Platform | Best Known For | Recommended For |
|---|---|---|
| **AWS** | Broad service selection and global infrastructure | Organizations with diverse workloads |
| **Microsoft Azure** | Microsoft integration and hybrid cloud | Microsoft-based enterprises |
| **Google Cloud** | AI, data analytics, and Kubernetes | Data-driven and cloud-native organizations |

### Summary

Each cloud provider has its own strengths. **AWS** is a strong general-purpose choice because of its extensive service portfolio, **Azure** is especially suitable for organizations already using Microsoft technologies, while **Google Cloud** is a strong option for organizations focused on artificial intelligence, data analytics, and Kubernetes.

The best cloud platform ultimately depends on the organization's technical requirements, existing infrastructure, budget, skills, and business goals.
